# 📚 Planificador de estudios

Planificador personal para estudiantes: organiza tu día a día de forma fácil y rápida.

🔗 **Pruébalo aquí:** https://rorrasvill.github.io/planificador-estudios/

## Qué incluye

- **Hoy**: agenda del día, próximas actividades y resumen de asignaturas.
- **Mes y Semana**: calendario mensual y cuadrícula por horas.
- **Metas**: objetivos con fechas límite.
- **Avisos**: recordatorios por actividad (aviso en la página, sonido y notificación).
- **Asignaturas**: apuntes, notas con peso, media y nota necesaria para aprobar.
- **Copia de seguridad**: exportar e importar tus datos en un archivo.

## Tus datos son tuyos

Todo se guarda en tu propio navegador (no hay servidor ni cuentas). Nadie más puede ver tus datos. Para pasarlos de un dispositivo a otro, usa Exportar/Importar copia.

## Ejecutar en local

Es HTML, CSS y JavaScript puros, sin instalar nada. Abre la carpeta en Visual Studio Code y usa la extensión Live Server sobre `index.html`.
